# RUBRIC — OKX Dev Day 2026 Evaluation Criteria

Submissions are judged on the following core pillars:

### 1. Technical Execution & Code Quality (25%)
- Clean architecture, modular design, reproducible local tests (`make test`).
- Robust Solidity contracts with invariant and failure coverage.
- Type-safe runtime and deterministic error handling.

### 2. Integration with X Layer & OKX AI (25%)
- Deep, native use of **OKX X Layer** (settlement, token movement, smart contracts).
- Integration with AI agent tooling and **MCP (Model Context Protocol)**.
- Real-world readiness on X Layer testnet.

### 3. Product Completeness & User Value (25%)
- Solves a severe real-world pain point: autonomous agents spending company money safely.
- Frictionless UX/DX: single kernel noun (**`Space`**), minimal cognitive overhead.
- End-to-end runnable demonstration without manual workarounds.

### 4. Innovation & Market Potential (25%)
- Beyond simple toy wallets: a foundational Commerce OS for human-agent coordination.
- Defensible primitive: bounded operating contexts with deterministic boundary enforcement.
- Direct alignment with OKX's vision for an open agentic economy on X Layer.
